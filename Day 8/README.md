# Day 8 - Pattern Printing
# What is Pattern Printing?
- Pattern printing is the process of using loops (`for`, `while`) to print shapes, numbers, or symbols in a specific format.
- It helps improve:
    - Loop concepts
    - Nested loops
    - Logic building
    - Problem-solving skills

# Types of Pattern Printing
