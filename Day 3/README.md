# Day 3 - Operators
# What are Operators?
- Operators are special symbols used to perform operations on variables and values.

# Types of Operators
- Opeartors are 7 types, i.e
    - Arithmetic Operators
    - Relational Operators
    - Logical Operators
    - Assignment Operators
    - Unary Operators
    - Ternary Operator
    - Bitwise Operator
# 1.Arithmetic Operators
- It is used for mathematical operations.

| Operator | Description | Example |
|----------|-------------|---------|
| + | Addition | a + b |
| - | Subtraction | a - b |
| * | Multiplication | a * b |
| / | Division | a / b |
| % | Modulus (Remainder) | a % b |


# 2.Relational Operators
- It is used to compare values and returns true/false

| Operator | Description | Example |
|----------|-------------|---------|
| == | Equal to | a == b |
| != | Not equal to | a != b |
| > | Greater than | a > b |
| < | Less than | a < b |
| >= | Greater than or equal | a >= b |
| <= | Less than or equal | a <= b |

# 3.Logical Operators
- It is used to combine conditions.

| Operator | Description | Example |
|----------|-------------|---------|
| && | Logical AND | (a > b && b > c) |
| || | Logical OR | (a > b || b > c) |
| ! | Logical NOT | !(a > b) |

# 4.Assignment Operators
- It is used to assign values.

| Operator | Description | Example |
|----------|-------------|---------|
| = | Assign | a = 10 |
| += | Add and assign | a += 5 |
| -= | Subtract and assign | a -= 5 |
| *= | Multiply and assign | a *= 5 |
| /= | Divide and assign | a /= 5 |
| %= | Modulus and assign | a %= 5 |

# 5.Unary Operators
 It operates on single value.

| Operator | Description | Example |
|----------|-------------|---------|
| ++ | Increment | ++a / a++ |
| -- | Decrement | --a / a-- |
| + | Positive sign | +a |
| - | Negative sign | -a |

# 6.Ternary Operator
-It is the short form of if-else. 

| Operator | Description | Example |
|----------|-------------|---------|
| ? : | Short if-else | (a > b) ? a : b |

# 7.Bitwise Operators

| Operator | Description | Example |
|----------|-------------|---------|
| & | AND | a & b |
| | | OR | a | b |
| ^ | XOR | a ^ b |
| ~ | NOT | ~a |
| << | Left shift | a << 2 |
| >> | Right shift | a >> 2 |
